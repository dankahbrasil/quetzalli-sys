Fonte dos dados e configurações

Os resultados vêm da API pública de resultados do TSE (resultados.tse.jus.br), lida direto pelo seu navegador. Os códigos das eleições são detectados automaticamente; se a detecção falhar, preencha-os aqui.

Plano B: dados colados. Se o navegador não conseguir ler o TSE, cole um CSV com as colunas uf;lula_1t;flavio_1t;lula_2t;flavio_2t;secoes_2t_pct (use BR para o total nacional e ZZ para o exterior; campo vazio = sem dado).

Notas
  • Percentuais calculados apenas sobre os votos de Lula e Flávio, inclusive no 1º turno, para comparar os dois turnos na mesma base.
  • Enquanto a apuração é parcial, a variação entre turnos depende de quais seções já foram totalizadas e pode mudar bastante.
  • "Exterior" soma os votos de brasileiros fora do país; o detalhe por país está na aba "Exterior por país".
  • Comparecimento = eleitores que compareceram ÷ eleitorado, nas seções já totalizadas segundo o TSE.
